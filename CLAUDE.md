## Project Overview

This is a basic Rust tutorial project containing a single binary executable (`main.rs`). It's designed as a learning exercise for Rust programming fundamentals.

## Development Commands

- **Build**: `cargo build`
- **Run**: `cargo run`
- **Run with arguments**: `cargo run -- <args>`
- **Debug build**: `cargo build --release`

## Project Structure

- `main.rs` - Main binary executable containing the tutorial examples
- `Cargo.toml` - Project manifest defining the package and dependencies

## Notes

This is a minimal tutorial project. All code is contained in `main.rs`. There are no modules, crates, or tests defined at this time.
